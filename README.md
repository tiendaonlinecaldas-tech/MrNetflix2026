# MrNetflix Pro & Don Streaming - Control de Clientes

Este repositorio contiene la aplicación autocontenida de **MrNetflix Pro**, optimizada para ejecutarse en la web y teléfonos móviles (PWA).

## 🚀 Despliegue en Netlify (30 segundos)
1. Entra a [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Arrastra y suelta la carpeta descomprimida o tu archivo `MrNetflix_Proyecto.zip`.
3. Netlify generará tu enlace seguro HTTPS al instante.
